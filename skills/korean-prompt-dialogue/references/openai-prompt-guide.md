# OpenAI 공식 프롬프트 가이드 적용

2026년 10월 9일 확인한 [ChatGPT Enterprise Prompting Guide](https://developers.openai.com/cookbook/examples/chatgpt/chatgpt_prompt_guide/chatgpt_prompt_guide)의 작성 원칙을 이 스킬에 맞춰 적용한다. 일반적인 작성 원칙을 참고한 것이며 공식 인증이나 성능 보장을 뜻하지 않는다. 아래 실행 승인 절차는 사용자 요구에 따른 스킬의 동작이다.

## 작업을 맡길 수 있는 수준으로 작성

- 배경: 무엇을 하려는지, 왜 필요한지, 사용할 입력과 현재 상태를 적는다. 받는 AI가 모르는 대화 맥락은 풀어 쓴다.
- 지시: 이번에 수행할 행동과 산출물을 구체화한다. 여러 목적이 섞였다면 첫 산출물과 후속 목표를 구별한다. 사용자 범위를 임의로 축소하지 않는다.
- 추가 정보와 제약: 필요한 독자·문체·형식, 유지·금지 조건, 입력 자료와 완료 기준을 명시한다.
- 정확성: 사실을 다루면 관련 출처를 요구하고 미확인 내용은 구분하게 한다. 제공 자료로 확인할 수 없는 값은 만들어 넣지 않는다.
- 개선: 사용자가 결과나 초안에 대해 수정하면 부족했던 맥락·형식·범위를 반영한다. 단순히 더 길게 쓰거나 표현만 전문적으로 바꾸지 않는다.

역할은 관점이나 전문성이 결과에 영향을 줄 때만 지정한다. 항상 “세계 최고의 전문가”를 붙이지 않는다. 명료한 구조가 기본이지만 고정된 유일 템플릿은 아니다. 분량·숫자·형식을 추가할 때에는 사용자 요구나 작업상 필요한 이유가 있어야 한다.

## 구성 예

```text
# 배경
사용자의 목표, 현재 상황과 실제 제공된 입력을 설명한다.

# 지시
이번 작업과 산출물, 필요한 수행 순서를 적는다.

# 추가 정보와 제약
범위와 유지·금지 조건을 적는다.
필요한 결과물 형식과 관찰 가능한 완료 기준을 명시한다.
중요한 미정 사항이나 필요한 자료를 확인할 방법을 적는다.
```

위 설명문을 그대로 출력하거나 입력용 빈칸을 남기지 말고 실제 대화의 내용으로 채운다. 정보가 충분한 간단한 작업에는 짧게 작성한다.

프롬프트 밖에서 “이 프롬프트로 작업을 진행해도 될까요?”라고 묻고 승인을 기다린다. 프롬프트 내부에 승인 문구만 넣는 것으로 현재 assistant의 승인 대기를 대신하지 않는다. 프롬프트 작성만 요청했거나 승인 생략을 명시한 경우에는 본문의 해당 모드를 따른다.
